# 手机屏幕自动点击工具

一个功能强大的手机屏幕自动点击工具，支持自定义位置、点击频率、循环次数、长按、滑动等功能。

## 功能特点

- **自定义点击位置**：支持多点定位和坐标输入
- **点击参数设置**：频率（每秒点击次数）、循环次数、点击时长
- **高级操作**：长按功能、滑动轨迹设置
- **操作序列**：支持录制和回放操作序列
- **可视化操作编辑**：直观的拖拽式操作序列编辑
- **定时执行**：设置任务在特定时间自动执行
- **序列保存与加载**：支持保存多个操作序列，随时加载使用
- **导出与导入**：支持导出操作序列为JSON文件，方便分享和备份

## 使用方法

1. 打开 `index.html` 文件
2. 在手机屏幕模拟区域添加操作点
3. 设置操作参数（频率、次数、延迟等）
4. 点击"开始"按钮执行操作序列

## 操作类型

### 点击操作
- 设置点击频率（次/秒）
- 设置点击次数（支持无限循环）
- 设置点击延迟（秒）

### 长按操作
- 设置长按时间（秒）
- 设置长按延迟（秒）

### 滑动操作
- 设置滑动速度（像素/秒）
- 设置滑动次数（支持无限循环）
- 设置滑动延迟（秒）

## 全局设置

- **全局循环次数**：整个操作序列的循环次数
- **操作间隔**：每个操作之间的间隔时间（秒）
- **定时执行**：设置操作序列在特定时间自动执行

## 屏幕设置

- **屏幕尺寸**：支持小屏（280×560）、中屏（320×640）、大屏（360×720）
- **背景颜色**：支持选择预设背景色或自定义背景色

## 浏览器兼容性

- Chrome 80+
- Firefox 75+
- Safari 13+
- Edge 80+

## 注意事项

1. 本工具仅用于模拟手机屏幕操作，实际应用需要配合自动化工具使用
2. 导出的操作序列文件可以在不同设备间共享使用
3. 长时间运行可能会导致浏览器性能问题，建议适当休息
